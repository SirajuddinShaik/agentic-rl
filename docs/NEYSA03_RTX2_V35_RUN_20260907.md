## Root cause fixed before this run

The previous neysa03 submissions failed after placement because `/data/aicloud/hf_models/NVIDIA-Nemotron-3-Nano-30B-A3B-BF16` existed on neysa03 but not inside the RTX2 Ray worker container. SGLang/Megatron treated the absolute path as a Hugging Face repository ID and raised `HFValidationError`.

The fix is a path alias inside `miles-rtx2-never-delete`:

```text
/data/aicloud/hf_models/NVIDIA-Nemotron-3-Nano-30B-A3B-BF16
  -> /data/siraj/hf_models/NVIDIA-Nemotron-3-Nano-30B-A3B-BF16
```

Both copies have matching hashes for `config.json`, `tokenizer_config.json`, and `chat_template.jinja`. `AutoConfig.from_pretrained(..., trust_remote_code=True)` was verified on RTX2 before relaunch.

The placement-group ordering was also corrected so the Ray head's eight H200s are selected first for the trainer and RTX2 GPUs 4-7 follow for rollout.
